# Folder Gambar & Media

Folder ini digunakan untuk menyimpan gambar pada portofolio:

1. **`profile.jpg`**
   - Pasfoto formal Ryfaathir Rahman (ukuran 3x4 atau 4x6 / rasio 1:1 persegi atau portrait).
   - Saat Anda menyimpan foto dengan nama `profile.jpg` di folder ini, foto tersebut akan otomatis tampil di bagian Hero/Beranda menggantikan placeholder.

2. **`galeri-foto.png`** (atau `.jpg`)
   - Tangkapan layar (screenshot) website Proyek Galeri Foto (Uji Kompetensi RPL).
   - Resolusi yang disarankan: 1920 × 1080 atau 1280 × 720 px.
   - Saat disimpan di sini dengan nama `galeri-foto.png`, otomatis menggantikan canvas placeholder proyek.
